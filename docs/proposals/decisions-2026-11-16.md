# 결정 기록 — 2026-11-16

제안서 001·002·003을 검토해 정한 내용이다. 이 결정은 2026-11-16에 [CLAUDE.md](../../CLAUDE.md)에 통합했다. 앞으로의 설계 기준은 CLAUDE.md이고, 이 문서와 제안서는 결정 이유를 남기는 기록이다.

## 배경

- 당분간 사용자 PC에서만 개발하고, 거의 완성됐을 때 GitHub에 올린다. 협업자(저장소 주인)와 합의했고, 세부 결정은 사용자가 한다.
- Firebase 프로젝트는 아직 없다. 당분간 Firebase 없이 가짜 데이터로 개발한다.
- 제안서와 CLAUDE.md가 따로 있으면 충돌하므로, 결정을 CLAUDE.md에 직접 반영했다.

## 통합 원칙

1. CLAUDE.md의 기존 절 번호와 구조를 유지하고, 새 내용은 해당 절에 합친다. 새 절은 6.10 활동 계획 하나만 만들었다.
2. 1절 절대 규칙은 문구를 바꾸지 않았다.
3. "보류" 또는 "Phase N 전 결정"인 항목은 본문에 확정 규칙으로 쓰지 않고, CLAUDE.md 11절에 미결로 옮겼다.
4. "임시값(전문가 검토 전)"인 항목은 본문에 쓰되 "(임시값, 전문가 검토 후 확정)"을 붙였다.
5. 제안서 파일은 지우지 않는다.
6. `assets/content/*.json`은 고치지 않았다. 바꿔야 하는 내용은 CLAUDE.md에 "콘텐츠 변경 예정"으로 적고, 아래 "콘텐츠 파일 변경 예정 목록"에 정리했다.
